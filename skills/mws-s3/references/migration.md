# Миграция

Сверь пулы, эндпоинты и возможности через pools/capabilities. Регион SigV4 равен выбранному пулу; адресация задаётся профилем. Передавай данные потоково, через presigned URL или multipart. Copy работает в пределах эндпоинта. Сверяй размеры и контрольные суммы до удаления источника. Возможности целевого облака проверяй по документации: https://mws.ru/docs/cloud-platform/storage/general/quickstart-aws-cli.html https://mws.ru/docs/cloud-platform/storage/general/object-overview.html https://mws.ru/docs/cloud-platform/storage/general/pricing.html https://mws.ru/docs/cloud-platform/storage/general/quotas-limits.html https://mws.ru/docs/cloud-platform/storage/general/access-presigned-url.html https://mws.ru/docs/cloud-platform/storage/general/object-lock-settings.html.
