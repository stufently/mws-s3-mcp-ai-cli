# Обмен файлом

`s3_presign_get` выдаёт ссылку на разрешённый ключ; укажи срок не выше 604800 секунд. Ограничение профиля может требовать живой проверки: MWS Cloud Platform: сервис документирует срок от 60 до 604800 секунд; используйте не меньше 60. Условные запись/удаление и ACL не подтверждены, нужна живая проверка.. Не записывай подпись в журналы. `s3_presign_put` может перезаписать объект и всегда требует подтверждения.
